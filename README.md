# Smart-Irrigation-System-AI-IoT
AI-based smart irrigation system using soil moisture data and machine learning


## Abstract
An AI-based smart irrigation system that uses soil moisture and temperature data to
automatically decide irrigation needs, reducing water wastage and improving crop yield.

## Technologies Used
- Python
- Machine Learning (Naïve Bayes)
- Flask
- Pandas, Scikit-learn
- Matplotlib, Seaborn

## Methodology
- Sensor data (soil moisture, temperature) collected
- Data used to train ML classifier
- Model predicts Pump ON / OFF
- Results evaluated using confusion matrix and accuracy

## How to Run
1. Install dependencies  
   pip install -r requirements.txt

2. Train model  
   python train_model.py

3. Visualize results  
   python evaluate_and_visualize.py

4. Run web app  
   python app.py

## Outcome
- Reduced water usage by 40–50%
- Improved irrigation accuracy
- Sustainable water management
